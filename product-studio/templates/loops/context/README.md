# Context packs

What a person (or the coding agent preparing a brief for one) reads before ruling on a gate. One
file per domain: product, design, tech, business, marketing. A gate names the packs it needs, and
a role's domains in the roster name the packs it answers from.

- Every fact is one bullet above the first `##` heading, ending with its source:
  `(source: <file path>)` or `(source: said by <name>, <date>)`. No source, no fact.
- `## Questions this pack's holder would ask`: the questions the expert always asks before
  agreeing. A brief answers each one or marks it open.
- Under 90 lines. No secrets, no customer data.

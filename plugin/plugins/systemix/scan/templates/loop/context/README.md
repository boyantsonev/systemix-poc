# Context packs

One short file per domain (business, product, design, tech, marketing). A deputy
reads the same facts the expert would have used before ruling at a gate.

Five sections, verbatim: `## What we know` · `## Numbers` · `## Open bets` ·
`## Sources` · `## Questions the expert would ask`. Under 90 lines. No secrets. Every
fact ends with its source. The owning role updates the pack after every decision
that changes a fact in it.

What the plugin does

0.1.0
/plugin marketplace add boyantsonev/systemix-poc
/plugin install systemix@systemix
/systemix:score
  • score

    Shows what the results file holds, asks before sending, then returns the free score (out of 100, per area) or, with a license key, the full report.

  • audits

    readiness-audit, design-audit, drift-report: read-only, scored from the published rubric, same numbers every run.

  • setup

    design-interview builds a design system from scratch; claude-design-sync brings a Claude Design output into tokens. Both propose and wait for a yes.

  • privacy

    The scan runs locally. Only the results file leaves, after a yes: counts, definitions, file paths, short names, no source code. Paths can be hashed. The license key sits in the plugin's secure settings, never in the chat.

Can your AI agents follow your design system?

Systemix is a Claude Code plugin that scores your design system for AI readiness, finds the drift and tells you what to fix first. The score is free, and your code never leaves your machine.

AARRR funnel in PostHog

run npm run posthog:funnel

One definition in src/lib/analytics/funnel.ts feeds the code and the dashboard script, which creates 6 charts. The plugin sends no user id, so web steps form a person funnel and server steps are counted weekly beside them.

Business model

prices are hypotheses
magnet · free€0

Plugin + score

Free and MIT. It runs on the client's own Claude, so a score costs us one short server call.

first money · self-serve€9.99

Quick report

Instant, no person. After VAT and Lemon Squeezy fees (about 5% + $0.50), roughly €7–9 per sale.

main revenue · human-reviewed€499

Full audit, 24h

AI drafts, a person rewrites the judged parts. Estimated 45–90 min each, so 3 a day per reviewer is plausible, not measured.

expansionQuote

Fix sprints

Make the fixes the audit names. Public budgets seen so far: $100–$720, so start small.
